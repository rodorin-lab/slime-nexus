# 🟢 Slime Nexus — 2.5D サイバーパンクゲーム

![Status](https://img.shields.io/badge/status-%E3%83%97%E3%83%AD%E3%83%88%E3%82%BF%E3%82%A4%E3%83%97-yellow) ![Stack](https://img.shields.io/badge/stack-Vite%20%2B%20TypeScript-blue)

**スライム × サイバーパンク** の2.5D探索ゲームプロジェクトだよ！

## 🎮 コンセプト

サイバーパンク都市を舞台に、スライムを操って探索・戦闘・進化！

## 🚀 起動方法

```bash
cd 2.5Dgame/slime_nexus
npm install
npm run dev
# http://localhost:3000 で開く
```

## 📂 プロジェクト構成

```
2.5Dgame/
├── slime_nexus/          # メインプロジェクト
│   ├── vite.config.ts    # Vite設定
│   └── app/              # アプリケーションコード
├── docs/superpowers/     # 設計ドキュメント
│   └── specs/            # 仕様書
└── .superpowers/         # ブレインストーム履歴
    └── brainstorm/       # アーキテクチャ検討
```

## 🛠 技術スタック

- **Vite** — 爆速ビルドツール
- **TypeScript** — 型安全な開発
- HTML5 Canvas / WebGL
